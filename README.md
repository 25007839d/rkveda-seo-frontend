# RKVeda SEO Frontend

React/Vite frontend for `seo.rkveda.in`.

## Setup

```bash
npm install
npm run dev
```

Production API defaults to `https://api.rkveda.in/api`. Override with `VITE_API_BASE_URL` in `.env`.

## Current flow
Login → Dashboard → Audits → Audit Detail.

Project ID is currently `1` for the first frontend milestone.
